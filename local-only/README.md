# 로컬 전용 자료

이 안내 파일만 Git 관리 대상입니다. 이 폴더의 다른 파일과 하위 폴더는 Git에서 제외합니다.

- `inputs/`: 실제 문서나 개인정보가 들어 있는 시험 입력
- `outputs/`: 해당 문서를 검사·수정한 결과
- `notes/`: 개인 작업 메모와 공유하지 않을 조사 자료

필요한 하위 폴더는 사용 시 만듭니다. 공유할 합성 예시 문서는 `test/fixtures/` 또는 `test/shared-document-examples/`에 둡니다.

기존 시험의 상세 실행 자료는 출력 경로를 유지한 채 `test/.gitignore`로 제외합니다. 구체적인 구분은 `test/README.md`를 참고하세요.

Git 제외 설정은 업로드 대상의 실수를 줄이는 장치입니다. 파일을 암호화하거나 접근 권한을 제한하지는 않습니다. 실제 자료를 강제 추가하지 마세요.

# 이 PC에만 보관할 자료

이 안내 파일만 GitHub에 공유합니다. 아래 자료는 `.gitignore`로 제외합니다. 암호화 폴더는 아니므로 PC 자체의 접근·보관 정책을 따르세요.

| 위치 | 보관 내용 |
|---|---|
| `inputs/` | 실제 사용자 문서·개인정보가 들어 있는 시험 입력 |
| `outputs/` | 수정 사본·상세 응답·화면 캡처·생성 보고서·묶음 ZIP |
| `notes/` | 개인 작업 메모·로컬 경로·환경 정보 |
| `archive/` | 제품과 무관한 과거 문서 작업·보관 자료 |

필요한 하위 폴더는 사용할 때 만듭니다. 이전 루트 `output/` 자료는 `outputs/`, 관련 없는 `reports/` 작업은 `archive/reports/`로 옮겼습니다. 과거 스크립트는 당시 환경·경로에 의존할 수 있습니다. 실행 중인 문서는 이전 경로에 열린 원본이 남을 수 있으며 공개 예시 사본과 별도로 Git에서 제외합니다.

공유할 가상 문서는 `examples/`, 회귀 입력은 `validation/fixtures/`에 둡니다. 상세 시험 자료는 `validation/.gitignore`의 제외 경로에도 저장합니다. 전체 기준은 [파일 배치 안내](../docs/REPOSITORY.md)를 참고하세요. 비공개 자료를 잘못 커밋했다면 ignore 추가만으로 과거 Git 이력에서 제거되지 않습니다.

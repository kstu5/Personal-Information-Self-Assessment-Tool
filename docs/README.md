# docs

| 위치 | 내용 |
|---|---|
| `features/` | 기능 적용 기록: 파일 검사(외부 도구 설치 안내 `file-tools.md` 포함), 가림 UI, A 모델 |
| `design/` | 설계·정책: 게시글/파일 검사 분리 화면 설계, 파일 검사·수정 사본 정책 |
| `verification/` | 검증 기록: 1차 구현 검증(`verification.md`), 초기 탐지 평가 결과 |
| `HANDOFF.md` | 상세 인수인계(`scripts/build/build_handoff.py`가 읽음) |
| `CHANGELOG.md` | 날짜별 적용 내역과 그 시점의 검증 상태 |
| `DEPENDENCIES.md` | 의존성 라이선스 메타데이터(`scripts/prepare/record_environment.py`가 생성) |

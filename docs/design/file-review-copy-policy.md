# 파일 검사·수정 사본 제공 방향

확정 근거: 2026-10-24 사용자 요청. 아래는 목표 정책이며 실제 적용 범위는 [파일 검사 적용 기록](../features/file-inspection.md)을 우선한다. 파일 검사·사본 저장을 앱에 연결했으며, HWP 수정 저장과 미지원 구조 등은 제한한다.

## 원본과 사본

파일 검사 기능은 원본을 편집하지 않는다. 원본을 읽어 별도의 작업 사본을 만들고, 사용자의 선택을 사본에 적용해 수정 사본을 제공한다.

1. 원본 선택·형식 확인 후 작업 사본 생성. 원본 내용의 해시와 사본의 출처를 기록한다.
2. 사본의 본문·표·부가 기록·이미지를 지원 범위에 따라 검사한다.
3. 사용자가 위치별로 전체 가림·부분 가림·유지·직접 수정을 선택한다.
4. 선택 결과를 사본에 적용하고, 새 파일로 쓴 뒤 재열기·위치·남은 원문을 재검사한다.
5. 사용자가 수정 사본을 저장한다. 기본 이름은 `원래이름_개인정보처리본.확장자` 형태로 한다.

원본과 같은 실제 경로 또는 원본을 가리키는 별칭에는 출력하지 않는다. 파일명 충돌은 새 이름으로 해결한다. 작업 중 원본이 변경됐으면 기존 검사 결과를 새 원본에 그대로 적용하지 않는다. 취소·실패 시 원본은 보존하며 검증하지 못한 출력을 완료 파일로 제공하지 않는다. 작업 사본은 로컬 임시 영역에서 관리하고 작업 종료 후 정리하는 정책을 구현한다.

이 원칙은 새로 구성할 **문서 파일 검사·내보내기**에 적용한다. 기존 게시글 `.piipost` 저장 동작을 이번에 변경한 것은 아니다.

## 검토 범위

본문 이외에 읽을 수 있는 다음 영역도 후보와 위치를 표시한다.

- DOCX: 메모 내용·작성자, 문서 속성, 남아 있는 변경 추적의 삽입·삭제 내용, 머리말·꼬리말 등.
- XLSX: 셀·수식 결과, 일반 셀 메모·작성자, 숨김 시트·행·열, 표시 형식, 연결·정의 이름 등.
- PPTX: 슬라이드 텍스트·표, 발표자 노트·노트의 개체, 작성자 등 문서 속성.
- HWPX/HWP: 지원되는 메모·변경 추적·작성자·각주·내부 미리보기 글자와 이미지 등. 미리보기는 수정 후 안전하게 재생성하거나 제거하는 절차가 필요하다. HWP는 실제 지원 범위를 더 좁게 판정한다.
- PDF: 본문·이미지·검색용 글자층, 주석·양식·첨부·메타데이터 등 지원되는 영역.

위 목록은 목표 범위다. 모든 항목이 검증되거나 구현된 것은 아니다. 현대식 스레드 댓글, 내장 문서, 복잡한 개체 등 미지원 요소를 `0건`으로 표시하지 않는다. 검사된 영역과 미검토 영역을 구분한다. 파일에 포함된 변경 기록만 읽으며 클라우드 서비스의 별도 버전 이력을 자동으로 조회하지 않는다.

검출 항목에는 `1쪽 본문`, `명단!B2 메모`, `3번 슬라이드 발표자 노트`, `삭제된 변경 기록`처럼 위치와 출처를 붙인다. 변경 추적 전체 승인·거부와 메모 일괄 삭제는 문서 의미를 바꾸므로 개인정보 가림과 별도의 선택으로 취급한다.

## 엑셀 값 전용 배포

사용자가 제안한 순서는 **계산 결과 확인 → 값으로 변환 → 개인정보 처리 → 재검사**다.

- 계산 결과 확인에는 사본의 강제 재계산과 결과 검증을 포함한다. 저장된 캐시가 존재한다는 이유만으로 최신값으로 인정하지 않는다.
- 외부 데이터·지원하지 않는 함수·계산 오류·확인할 수 없는 빈 결과가 있으면 해당 내보내기를 중단하거나 확인 필요로 남긴다. 임의의 0·빈칸으로 대체하지 않는다.
- 정상 수식 결과를 값으로 고정한 후, 그 값과 다른 셀·숨김 영역·메모까지 개인정보 처리를 한다.
- 값으로 바꾼 사본은 원래 입력을 바꿔도 재계산되지 않는다. 사용자에게 `값 전용 배포 사본`과 계산 기준 시점을 안내한다.
- 수식 자체를 유지하는 원본은 그대로 보존한다. 지원할 함수·외부 연결·차트·피벗 등의 범위는 추가 검증으로 결정한다.

## PDF와 이미지

PDF는 선택된 원문·해당 이미지 픽셀·겹친 검색용 글자층을 삭제한 뒤 가림 표시를 적용한다. 단순 도형 덮기나 증분 저장만으로 완료하지 않는다. 새 파일에서 텍스트와 내부 이미지를 다시 추출해 확인한다.

이미지는 원래 픽셀을 불투명하게 바꿔 새 이미지로 저장한다. 전체 가림과 부분 가림을 지원하는 방향으로 한다. 부분 가림은 성·전화번호 앞뒤처럼 남길 부분을 유지하거나, 지운 자리에 `*`를 다시 그리는 방식이다. 이미지 파일의 원문 메타데이터와 문서 안에 남은 원본 이미지 복사본도 확인해야 한다.

OCR 결과가 틀리거나 좌표가 불확실하면 사용자가 영역을 직접 지정·조정할 수 있게 한다. 부분 가림은 일부 정보를 남기는 선택이며, 완전 익명화와 같은 의미로 표시하지 않는다. 흐림·모자이크를 기본 처리로 삼기보다 불투명한 픽셀 교체를 우선한다.

## 시험 데이터

성명 예시는 `김민수`, `이지은` 등 일반적인 이름을 쓰되 특정 실존 인물의 자료를 수집하지 않고 합성 문맥으로 구성한다. `박하차`는 음료·활동 같은 일반 단어의 오탐 시험에만 사용하고 명단의 성명 칸에 넣지 않는다. 개인정보 탐지 성능과 파일 수정·보존 성능은 별도로 평가한다.

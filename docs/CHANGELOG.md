## 2026-10-25 직접 수정 입력란 이동 수정

- 검출 목록을 스크롤한 뒤 직접 수정을 선택하면 입력란이 화면 위에 가려지는 현상을 재현했습니다. 선택한 항목을 편집하라는 표시가 중간 연결에서 누락되고, 방법 변경만으로는 입력란으로 이동하지 않던 문제였습니다.
- 검출 목록·처리 버튼·아래 적용 목록의 편집을 같은 경로로 연결했습니다. 선택한 항목의 입력란을 화면 안으로 이동하고 커서와 기존 내용 선택을 제공하며, 입력 중에는 재선택하지 않습니다.
- TXT·HWPX·CSV에서 화면 입력 → 사본 생성·재검사 → 저장 파일의 문구와 원본 해시를 확인했습니다. 관련 시험 11개·TypeScript 검사·빌드를 통과했습니다. [재현과 검증](verification/direct-edit-ui-2026-10-25.md)을 참고하세요.

## 2026-10-25 사용 모델 명시와 예시 12종 미리보기

- 모델명 표기를 실제 식별자 `atonlee/koelectra-ko-pii-ner`로 통일했습니다. 파일 화면에 이름·주소 모델과 ko-pii 규칙의 역할을 표시하고 검사 진행·결과의 엔진명과 설명·확인 도구도 맞췄습니다. 설치 경로와 고정 모델 파일은 유지했습니다.
- TXT·HWPX·HWP에는 읽어낸 본문 순서로 구성한 내용 미리보기를, CSV·TSV에는 행·열과 빈 셀 위치를 유지한 표를 연결했습니다. 본문 밖 정보는 기존 텍스트·위치 검토에 남깁니다. HWP는 읽기 전용입니다.
- 실제 모델·API로 예시 12종의 기본 미리보기를 확인했고 새 내용/표 화면의 TXT·CSV·TSV·HWPX 수정 사본 생성·재검사를 통과했습니다. 원본 해시 12/12 유지, Python 시험 95개·화면 관련 시험 11개 통과. [형식별 적용·한계·검증](features/file-preview-formats.md)을 참고하세요.

## 2026-10-25 원본·적용 미리보기 전환과 처리 지정 표시

- 사본을 만들기 전 원본과 적용 미리보기를 전환합니다. 처리 방법을 정하면 미리보기를 자동으로 열고, 원본으로 돌아와도 지정 내용은 유지합니다.
- 문서의 체크 표시·목록 배경·상태 배지·처리 지정 개수로 미설정과 부분/전체 가림·직접 수정·명시적 유지를 구분합니다. 처리 선택 취소는 다시 미설정으로 돌립니다.
- Word·PPT는 원본 위치에 변경 모습을 겹쳐 보여주는 간이 미리보기, PDF·이미지는 선택 영역의 불투명 가림, 텍스트·Excel은 원문 위치별 변경 내용을 표시합니다. 실제 사본 확인·재검사는 별도입니다.
- TypeScript 검사·화면 빌드와 관련 시험 9개 통과. 실제 가상 DOCX·PDF·XLSX에서 전환·선택 유지·취소·명시적 유지를 확인했습니다. [검증 기록](verification/file-draft-toggle-2026-10-25.md)에 범위와 제한을 남겼습니다.

## 2026-10-25 문서 화면과 가림·수정 연결

- Word·PowerPoint를 읽기 전용 페이지로 표시하고 개인정보 표시와 검출 목록을 연결했습니다. 선택한 항목의 부분 가림·전체 가림·직접 수정을 오른쪽에서 지정합니다.
- 원본 화면과 실제 수정 사본 화면을 구분합니다. 사본 화면에는 재검사한 남은 후보를 표시하며, 사본을 다시 만들면 이전 사본의 페이지 캐시를 정리합니다.

파일 선택 창의 경로 선택만 시험 코드에서 임시 경로로 대체했습니다. 디스크 읽기·쓰기는 실제로 수행했고 탐지 결과는 실제 엔진을 사용했습니다. OS 파일 선택 창에서 직접 폴더를 고르는 조작, PC 재부팅, 다른 LAN 기기에서의 접속, 다른 Windows PC에서의 설치는 별도 사용 확인이 필요합니다. 설치형 EXE 배포와 코드 서명은 아직 제공하지 않습니다.

이름·주소의 오탐·미탐은 여전히 존재합니다. 이전 비교 시험에서는 “박하차” 오탐과 띄어 쓴 이름 일부의 누락이 남았습니다. 예시 글의 “아래”, “두었던” 오탐과 주소 호수 누락은 이번 화면 시험에서 개선을 확인했습니다. 작은 시험 표본의 결과를 일반적인 탐지 정확도 보장으로 해석하지 않습니다. `docs/verification/verification.md`는 적용 이전 기록입니다.

## 범위와 주의점

이번 실제 API 확인은 경로 변경 후 읽기·표시·일부 수정 경로가 유지되는지 확인한 시험입니다. 일반적인 개인정보 탐지 정확도를 새로 측정한 결과는 아닙니다. 모든 문서의 가림 성공·한컴 원본 배치 호환성·새 PC 설치·설치판 업그레이드·Linux 동일 지원은 검증하지 않았습니다.

화면·실행 제목·설치 메타데이터의 표시명은 바꿨으며 저장 형식의 `before-post-document`, Windows 기존 설치 경로와 AppId, 중복 실행 식별자, 모델 폴더의 `model-a`는 호환성을 위해 유지했습니다. GitHub 저장소 주소와 현재 작업 폴더 이름도 그대로입니다.

다른 프로그램에서 열려 있어 이동이 잠긴 이력서 DOCX는 새 공개 위치에 같은 내용의 사본을 두었습니다. 열린 원본은 이전 `test/` 경로에 남기고 Git 추적에서 제외했습니다. 사용자 작업을 닫거나 원본을 삭제하지 않았습니다. 과거 Git 이력을 다시 쓰지 않았으므로 예전에 커밋된 생성물은 과거 이력에 남습니다.

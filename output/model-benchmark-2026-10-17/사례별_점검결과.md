# 사례별 점검 결과

정답과 원래 모델 출력을 그대로 대조한다. 위치는 Python 문자 기준 [시작, 끝)이며 정답·원문을 결과에 맞춰 수정하지 않았다. A의 일반 날짜·장소 등 비개인정보 출력도 이 원시 출력 표에는 남겨 두었다.

## N001 · name · 소개

```text
안녕하세요. 이번 행사를 준비하는 김하늘입니다.
```

| 구분 | 구간·유형 |
| --- | --- |
| 정답 | 김하늘 → PERSON [19, 22) |
| 현재 규칙 | 없음 |
| A 단독 | 김하늘 → PERSON [19, 22) |
| B 단독 | 김하늘 → PERSON [19, 22) |

# 게시 전 프로젝트 인수인계 읽기 안내

기준일: 2026년 10월 16일

이 자료는 지금까지의 대화와 구현을 이어받기 위한 문서 및 소스 사본입니다. 설치형 프로그램이 아니며, ZIP을 풀었다고 모든 실행 환경이 준비되는 것은 아닙니다.

## 먼저 확인할 파일

1. `01_상세인수인계.md` 또는 ZIP에 담긴 `02_상세인수인계.pdf`: 기획부터 모델 연결 논의까지의 흐름, 현재 기능, 시험 결과, 다음 작업.
2. `다음담당자_시작요청.txt`: 새로운 담당자나 새 채팅에 전달할 시작 요청.
3. `project/README.md`: 실제 실행과 설치 방법.
4. `project/docs/verification.md`: 기존 검증과 아직 확인하지 않은 범위.
5. `project/output/community-review`: 합성 작업 파일 3개와 실제 탐지 결과.
6. `project/research/논문기반_오탐과_미탐_개선방안.md`: 논문 원문 링크, 오류 원인 단서, 개선 제안.

## 현재 상태

- Windows 전용 창, React + TypeScript + Vite 화면, Python + FastAPI + ko-pii 1.16.0 연결이 구현됐습니다.
- 제목·본문 검사, 위험도별 글자색과 후보 목록, 파일 저장·불러오기가 동작합니다.
- 저장 위치는 사용자가 선택합니다. 작업 파일은 암호화되지 않은 .piipost JSON입니다.
- 학습 모델 연결·추가 학습, 오탐 개선 규칙, 마스킹, 첨부·OCR, 스마트폰·macOS, 설치형 EXE는 아직 구현하지 않았습니다.
- 이름·상세 주소·숫자 용도·물건 규격에서 오류가 남아 있습니다. 세 합성 글의 현재 후보 수는 각각 7, 9, 6개입니다. 후보가 많다는 것이 검사가 더 정확하다는 의미는 아닙니다.

## 실행

현재 PC에서는 원래 프로젝트 폴더의 `게시전 실행.vbs`를 사용합니다. 원래 폴더의 `.runtime`, `dist`, `runtime.local.json`을 유지해야 합니다.

다른 Windows PC에서는 ZIP의 `project` 폴더를 기준으로 Python, Node.js, pnpm, WebView2를 준비하고 README에 따라 `scripts/setup.ps1`을 실행합니다. 최초 설치에는 인터넷이 필요합니다. Python과 pnpm이 PATH에 없다면 스크립트 인자로 각각의 실행 경로를 전달합니다.

## 자료 범위

`project`에는 선별한 제품 소스, 잠금 파일, 시험 도구, 조사 문서와 기존 보고서가 있습니다. `reference`에는 원계획서, 가상 디자인 시안, 이전 시험 화면 캡처가 있습니다. 캡처는 이번에 다시 촬영한 화면이 아니라 기존 검증 자료입니다.

Python 실행기·의존성 폴더·빌드 폴더·현재 PC의 런타임 설정·Git 폴더·임의 사용자 초안은 제외했습니다. .piipost는 명시한 가상 시험 파일 3개만 포함합니다. 다른 PC에서는 설치와 빌드가 필요합니다.

Git 저장소에는 아직 커밋이 없었습니다. `manifest.json`에 묶음의 파일별 SHA-256과 크기가 있고 ZIP의 무결성도 확인했습니다. 검증값은 변경 여부 확인용이며 전자서명은 아닙니다.

## 문서가 충돌할 때

최신 사용자 결정 → 현재 코드와 검증 기록 → 이 인수인계의 상태 정리 → 과거 기획·연구 문서 순서로 대조합니다. 과거 연구 문서의 ‘구현 전’이라는 문구는 당시 기록입니다. 원계획서의 마스킹과 첨부 기능을 현재 구현 완료로 오해하지 마세요.

인수 시점의 빌드와 백엔드 시험은 다시 통과했습니다. 네이티브 파일 선택창 직접 조작, PC 재부팅, 다른 PC 설치 등은 아직 별도 확인이 필요합니다. 세부 기록은 `인수시점_확인기록.json`에 있습니다.

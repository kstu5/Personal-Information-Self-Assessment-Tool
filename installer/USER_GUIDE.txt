개인정보 자가진단 도구 0.1.4 사용 안내

설치와 업데이트
1. 이전 버전에서 필요한 글과 수정 사본을 저장하고 앱을 종료합니다.
2. 설치 EXE를 실행해 설치 폴더를 선택합니다. 전체 경로는 100자 이하로 지정하세요.
3. 인터넷에 연결한 상태로 설치가 끝날 때까지 기다립니다.
4. 시작 메뉴의 개인정보 자가진단 도구를 실행합니다.

Windows x64 온라인 설치판입니다. Python·모델·OCR·Java·LibreOffice·필요한 WebView2를
설치 중 준비하므로 사용자가 Python·Node.js·JDK를 따로 설치할 필요가 없습니다.
설치 이후 검사는 PC 안에서 수행하며 문서나 인증정보를 외부 생성형 AI API로 보내지 않습니다.
EXE에는 코드 서명이 적용되지 않았습니다. Release의 SHA256SUMS.txt로 무결성을 확인하세요.

처음 확인하기
시작 메뉴의 예시 문서 또는 설치 폴더 examples/formats/files/에 문서 12종이 있습니다.
게시글 예시 10개는 examples/posts/에 있습니다. 모두 합성 예시입니다.
.piipost는 게시글 검사에서 불러오며 파일 검사에 추가하는 형식이 아닙니다.

0.1.4 주요 변경
- 게시글 검출 목록 검색·필터, 오탐 제외, 누락 항목 검색·추가와 드래그 범위 지정
- 게시글과 파일의 위험도 요약·원본/적용 미리보기·원문 옆 편집 및 검출 목록 배치 통일
- 사용자 추가 항목의 유형 선택과 추가 후 유형 변경
- 사용자가 실행하는 개인정보 자동 가림 일부 정보 확인용
- Word·PPT·PDF·이미지 페이지에서 확인된 원문 글자 직접 드래그 선택
- 지원 HWP 5의 부분·전체 가림·직접 수정과 수정 사본 저장 및 검증

파일 검사
1. 파일 추가 또는 드래그 앤 드롭으로 파일을 엽니다.
   파일당 20MB, 최대 8개, PDF 최대 40쪽, 내장 이미지 최대 40개입니다.
   ZIP이나 폴더 전체를 추가하지 말고 안의 문서·이미지를 선택하세요.
2. 검출 목록에서 오탐을 한 곳·여러 곳·검색 결과 선택으로 제외합니다.
3. 누락 문구는 원문 검색으로 한 곳·여러 곳·전체 위치를 선택하거나 원문을 드래그해 추가합니다.
   추가할 정보 유형을 고를 수 있고, 추가 후 사용자 추가 유형에서도 바꿀 수 있습니다.
4. 남은 후보에 부분 가림·전체 가림·직접 수정·가리지 않음을 지정합니다.
   현재 파일 후보에 일괄 적용은 미설정 후보를 대상으로 하며 기존 지정을 유지합니다.
5. 원본/적용 미리보기를 비교하고 사본 생성·재검사를 실행합니다.
6. 실제 사본과 남은 후보를 확인한 뒤 확인란을 체크하고 새 파일로 저장합니다.
   원본 파일에는 덮어쓰지 않습니다. 사본을 원래 문서 프로그램에서도 열어 확인하세요.

게시글 검사
1. 제목·본문을 입력하거나 저장한 글 불러오기에서 .piipost를 선택해 검사합니다.
2. 검출 목록 검색·위험도·처리 상태 필터로 원문 위치를 확인하고 오탐을 제외합니다.
3. 원문 검색 결과를 선택하거나 원본 글자를 드래그해 누락 내용을 추가합니다.
   추가만으로 가리지는 않습니다. 가림 후에도 누락 항목 추가 또는 원본에서 계속 추가를 누르세요.
4. 처리 방법을 지정하고 원본/적용 미리보기를 비교합니다.
5. 저장하거나 수정한 글로 이어쓰기를 선택합니다.
제목은 300자, 본문은 30,000자까지 검사합니다.
.piipost에는 처리 결과 제목·본문만 저장합니다. 추가·제외 목록과 처리 이력은 저장하지 않습니다.
암호화되지 않은 JSON 작업 파일이므로 보관·공유할 위치를 확인하세요.

사용자 추가와 제외
유형 미지정은 참고에 표시합니다. 유형 선택 시 해당 유형의 기본 위험도·가림 기준을 사용합니다.
사용자 지정은 모델의 확정 판정이나 번호·인증정보의 실제 유효성 검증이 아닙니다.
기존 사용자 항목의 유형을 바꿔도 원문 위치와 처리 선택은 유지됩니다.
제외는 원문 삭제가 아니라 현재 후보·가림 대상에서 빼는 작업입니다.
제외한 내용이 필요하면 원문에서 새 항목으로 추가하며 이전 처리 설정은 복원하지 않습니다.
이 작업은 현재 글·파일에만 적용되며 다른 자료나 탐지 기준에 학습하지 않습니다.
다시 불러오거나 새 사본을 재검사하면 제외했던 정보가 후보로 다시 나올 수 있습니다.

자동 가림 일부 정보 확인용
개인정보 자동 가림을 누르면 유형별 기준과 적용 수를 먼저 보여줍니다.
기준대로 적용을 눌러 실행하며 기존 개별 처리·제외는 유지합니다. 저장은 별도로 합니다.
이름 첫 글자, 전화 앞자리·끝 4자리, 이메일 첫 글자·도메인, 주민·외국인번호 앞 6자리,
금융번호 끝 4자리, 출생연도·연령대·행정구역 등을 남깁니다.
여권·운전면허번호와 API 키·비밀번호는 전체를 가립니다.
사건·문서·민원번호 등 개인 연결 여부가 불명확한 항목은 직접 확인 대상으로 남깁니다.
자동 가림 되돌리기는 직전 자동 적용을 취소하며 이후 개별 변경은 유지합니다.
이 기능은 익명화를 보장하지 않습니다. 남긴 정보와 문맥으로 개인을 추측할 수 있습니다.

기본 처리와 표시
자동 검출한 API 키·인증 토큰·비밀번호는 전체 가림을 기본 지정합니다.
부분 가림을 선택해도 전체를 가리며 독립 이미지에서는 비공개 표시를 사용합니다.
주민·외국인·운전면허·여권번호는 기본 부분 가림이며 자동 가림 기준과는 다를 수 있습니다.
텍스트 전체 가림은 표시 글자마다 █ 한 개를 사용하고 공백·줄바꿈은 유지합니다.
미설정 후보와 가리지 않음은 원문을 남깁니다. 체크 표시는 처리 지정이며 저장 완료가 아닙니다.

이미지와 문서의 차이
PNG·JPG·JPEG는 원문 픽셀을 지우고 부분 가림 문구·비공개·직접 문구를 표시합니다.
직접 수정은 한 줄 80자 이하이며 빈 문구는 삭제입니다. 출력은 PNG입니다.
글자 크기를 유지하고 같은 줄의 빈 공간을 쓰지만 글꼴·배경은 원본과 다를 수 있습니다.
공간 부족·미지원 문자·겹침이 있으면 경고하고 사본 생성을 거부합니다.
직접 영역 가리기는 사각형을 확대 확인·조정한 뒤 확정하며 원문 픽셀을 검게 지웁니다.
PDF·문서 내장 이미지는 영역 가림을 지원하고 새 문구 교체는 지원하지 않습니다.
원문 검색은 읽힌 글자만 찾습니다. OCR 미인식 부분은 직접 영역으로 보완하세요.
Word·PPT 페이지는 확인된 원문 위치만 연결하며 모호하면 원문 텍스트에서 선택합니다.
엑셀은 지원 수식을 재계산한 값 전용 사본으로 제공하며 그림·차트 등은 제한됩니다.
HWP/HWPX 내용 화면은 원래 쪽·표 배치를 재현하지 않습니다.
HWP 5는 원본 문단·글자 위치에 반영하고 저장 후 텍스트·이미지·기록과 독립 읽기를 검증합니다.
미리보기·요약 속성·저장 이력·스크립트·외부 연결 설정·서명은 사본에서 제거합니다.
긴 수정 문구는 줄바꿈·쪽수가 달라질 수 있습니다.
암호화·변경 추적·첨부·OLE·외부 그림 등 검증할 수 없는 구조는 처리 또는 저장이 제한됩니다.
필드 결과 등 다시 채워질 수 있는 글자 구간은 수정 제한을 표시하고 자동 가림에서 제외합니다.

검사 결과를 읽을 때
기본 검사는 atonlee/koelectra-ko-pii-ner와 규칙을 사용합니다.
선택 기능 Qwen3.5-0.8B는 시험용이며 가중치·추가 실행 도구를 자동 설치하지 않습니다.
일부 실제 개인정보를 제외한 사례가 있어 기본으로 활성화하지 않습니다.
이름·기관명·일반 표현, 표의 항목명, 일정·생년월일, 학력·학교 약칭을 잘못 판단할 수 있습니다.
OCR는 저화질·기울기·필기·복잡한 표에서 글자나 위치를 잘못 읽을 수 있습니다.
검출 0건이나 재검사 0건이 개인정보가 없다는 보장은 아닙니다.
공유 전 본문 밖의 메모·노트·숨김 영역과 실제 저장 사본도 직접 확인하세요.
이 도구는 악성코드·바이러스 탐지 도구가 아닙니다.

문제가 생겼을 때
설치 실패는 설치 폴더 install.log에서 실패 단계를 확인하고 충분한 공간·인터넷 연결을 점검하세요.
이미지 수정 경고는 문구를 짧게 바꾸거나 영역 가림으로 보완하세요.
문서 페이지가 없으면 텍스트·위치에서 확인하고 읽지 못한 부분을 따로 검토하세요.
지원 제한이나 실제 제거 검증 실패를 무시해 공유하지 말고 구조를 정리한 사본으로 다시 검사하세요.
문제를 전달할 때는 버전·파일 형식·위치·동작을 적고 실제 개인정보·인증정보는 지우세요.

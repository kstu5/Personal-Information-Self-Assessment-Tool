개인정보 자가진단 도구 — Windows 설치판

1. GitHub Releases에서 PrivacySelfAssessmentTool-Setup-<버전>.exe를 받습니다.
2. 실행 중인 이전 버전에서 작업을 저장하고 종료합니다.
3. 설치 파일을 실행하고 설치가 완료될 때까지 기다립니다.
4. 시작 메뉴의 '개인정보 자가진단 도구'로 실행합니다.

설치에는 인터넷 연결과 충분한 디스크 공간이 필요합니다.
실행 환경, 탐지 모델, OCR, Java, LibreOffice 등을 설치 중 내려받습니다.
Python·Node.js·JDK를 사용자가 별도로 준비하거나 소스를 빌드할 필요가 없습니다.
설치 이후 개인정보 검사는 PC 안에서 수행합니다.

문제가 생기면 설치 폴더의 install.log와 오류가 난 단계를 확인하세요.
로그를 외부에 보내기 전 사용자 이름·개인 경로 등 불필요한 정보를 지우세요.
GitHub: https://github.com/kstu5/Personal-Information-Self-Assessment-Tool

검출 결과는 검토를 돕는 후보이며 모든 개인정보의 검출을 보장하지 않습니다.
원본·적용 미리보기·실제 수정 사본을 확인하고 공유 여부를 직접 결정하세요.
HWP는 읽기 전용입니다. PDF·이미지는 영역 가림만 지원합니다.

설치 프로그램에 코드 서명 인증서를 적용하지 않았습니다.
Release의 SHA256SUMS.txt로 다운로드 파일의 무결성을 확인할 수 있습니다.
완성 EXE는 Releases에서 받고, 'Source code' ZIP은 개발용으로 구분하세요.

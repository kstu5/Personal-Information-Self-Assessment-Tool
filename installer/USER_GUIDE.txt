개인정보 자가진단 도구 0.1.2 — Windows 설치판

1. 실행 중인 이전 버전에서 필요한 사본을 저장하고 프로그램을 종료합니다.
2. 설치 EXE를 실행하고 설치 폴더를 선택합니다.
   설치 폴더의 전체 경로는 100자 이하로 지정하세요. 너무 길면 설치 전에 안내합니다.
3. 인터넷에 연결한 상태로 설치가 완료될 때까지 기다립니다.
4. 시작 메뉴의 '개인정보 자가진단 도구'를 실행합니다.

Python·Node.js·JDK를 사용자가 따로 준비하거나 소스를 빌드할 필요가 없습니다.
실행 환경·모델·OCR·Java·LibreOffice·필요한 WebView2를 설치 중 내려받습니다.
전체 설치 용량은 EXE 다운로드 크기보다 큽니다. 설치 이후 검사는 PC 안에서 수행합니다.

시작 메뉴의 '개인정보 자가진단 도구 예시 문서' 또는
설치 폴더의 examples/formats/files/에서 합성 예시 12종을 열 수 있습니다.
파일은 한 번에 8개까지 열 수 있으므로 두 묶음으로 검사하세요.

게시글 예시 10개는 설치 폴더의 examples/posts/와 시작 메뉴의
'개인정보 자가진단 도구 게시글 예시'에서 찾을 수 있습니다.
게시글 검사 → 저장한 글 불러오기에서 .piipost 파일을 선택하세요.
수정한 글은 다른 이름으로 저장해 사용할 수 있습니다.
.piipost 파일은 파일 검사에 추가하는 형식이 아닙니다.

0.1.2는 API 키·인증 토큰·비밀번호 탐지와 유형별 기본 가림 설정을 추가했습니다.
개인정보 후보 탐지 → 인증정보 후보 탐지 → 유형별 문맥 검토 순서로 진행합니다.
알려진 키 형식과 주변 항목명·문장·표 구조를 사용하며 추가 모델은 필요하지 않습니다.
실제 키의 유효성·권한이나 비밀번호의 로그인 성공 여부는 외부에 전송해 확인하지 않습니다.
새로운 서비스 키 형식이나 OCR로 잘못 읽힌 값은 놓칠 수 있습니다.

기본 가림 설정
- API 키·인증 토큰·비밀번호: 전체 가림을 기본 지정합니다.
  부분 가림을 선택해도 전체를 가리며 독립 이미지에서는 비공개 표시로 처리합니다.
- 주민등록번호·외국인등록번호·운전면허번호·여권번호: 부분 가림을 기본 지정합니다.
  표준 주민·외국인등록번호는 앞 6자리 숫자를, 운전면허·여권번호는 첫 글자를 남깁니다.
- 나머지 유형: 처리 방법을 직접 선택합니다. 미설정 값은 원문으로 남습니다.
기본 화면은 원본입니다. 적용 미리보기에서 처리 예정 모습을 확인하세요.
파일은 사본 생성·재검사를 실행하고 남은 후보를 확인한 뒤 새 파일로 저장합니다.
이미 공유한 키는 폐기·재발급을 검토하고 비밀번호는 해당 서비스에서 변경하세요.

설치판의 파일 추가는 Windows 기본 파일 선택 창을 사용합니다.
브라우저에서는 지원되는 경우 운영체제 파일 선택 기능을 우선 사용하며,
미지원 환경에서는 기존 선택 창으로 동작합니다. 창 모양은 환경에 따라 다릅니다.
기존 문서 미리보기·페이지 이동·검사 진행 화면도 계속 제공합니다.
문서 페이지와 이미지 화면의 이전·다음 버튼으로 이동할 수 있습니다.
파일 드래그 앤 드롭도 계속 지원합니다.
파일 검사 화면에 탐색기의 문서·이미지 파일을 끌어 놓거나 '파일 추가' 버튼을 누르세요.
여러 파일을 함께 놓을 수 있으며 파일당 20MB, 목록에 최대 8개까지 열 수 있습니다.
폴더 전체는 지원하지 않습니다. 파일 추가 중에는 완료된 뒤 다시 놓아 주세요.
이전 버전을 설치했다면 작업을 저장하고 앱을 종료한 뒤 0.1.2 설치 파일로 업데이트하세요.

검출 항목에서 부분 가림·전체 가림·직접 수정·가리지 않음을 선택합니다.
원본/적용 미리보기로 비교하고 사본 생성·재검사 후 새 파일로 저장합니다.
PNG·JPG·JPEG는 원문 픽셀을 지운 뒤 별표·비공개·직접 문구를 표시합니다.
글자 크기를 유지하고 같은 줄의 빈 공간을 활용하며 기호는 로컬 글꼴이 지원하는 범위에서 표시합니다.
입력은 한 줄 80자 이하입니다. 공간 부족·미지원 문자는 미리보기와 경고를 함께 보여 주며 사본 생성은 거부합니다.
직접 영역 가리기는 검은 가림입니다. 수정 이미지의 출력 형식은 PNG입니다.

HWP는 읽기 전용입니다. HWP/HWPX 화면은 원래 쪽 배치를 재현하지 않습니다.
PDF·문서 내장 이미지는 영역 가림을 지원하고 새 문구 교체는 지원하지 않습니다.
엑셀은 지원 수식 재계산 후 값 전용 사본으로 제공합니다.
현재도 오탐과 누락이 발생합니다. 일반적인 지원 조건·목록 표현을 개인 정보로
해석하거나, 문장·표의 항목명을 잘못 연결하는 경우가 있습니다.
특히 학력·학교 약칭의 문맥 판정 등에는 남아 있는 오탐이 있습니다.
검출 결과는 확정 판정이 아닌 후보이며, 검출 0건은 개인정보가 없다는 보장이 아닙니다.
URL 뒤의 한국어 조사나 설명 일부가 검출 범위에 포함될 수 있습니다.
원문 위치와 남은 후보, 실제 수정 사본을 함께 확인하세요.

기본 검사는 KoELECTRA와 규칙을 사용합니다. Qwen3.5-0.8B 2차 문맥 검토는
시험용 선택 기능으로 제공하며, 가중치와 추가 실행 도구는 자동으로 설치하지 않습니다.
선택 기능에는 실제 개인정보를 제외하는 누락 사례도 있어 기본으로 활성화하지 않습니다.

설치 문제는 설치 폴더의 install.log에서 실패 단계를 확인하세요.
로그를 공유하기 전 사용자 이름·개인 경로 등 불필요한 정보를 지우세요.
설치 EXE에는 코드 서명을 적용하지 않았습니다.
Release의 SHA256SUMS.txt로 EXE와 예시 ZIP의 무결성을 확인할 수 있습니다.
'Source code' ZIP은 개발용 소스이며 완성 설치 프로그램과 다릅니다.

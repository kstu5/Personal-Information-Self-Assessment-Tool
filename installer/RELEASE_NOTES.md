Windows x64용 개인정보 자가진단 도구 설치판입니다.

1. **PrivacySelfAssessmentTool-Setup-버전.exe**를 다운로드하고 실행합니다.
2. 인터넷에 연결한 상태로 설치 완료까지 기다립니다.
3. 시작 메뉴의 **개인정보 자가진단 도구**로 실행합니다.

Python·Node.js·JDK를 직접 설치하거나 소스를 빌드할 필요가 없습니다. 이 EXE는 온라인 설치판으로 실행 환경·탐지 모델·OCR·Java·LibreOffice 등을 설치 중 내려받습니다. 설치 후 개인정보 검사는 PC 안에서 수행합니다.

`SHA256SUMS.txt`는 설치 파일의 SHA-256입니다. `INSTALLATION-CHECK.json`은 설치한 환경의 검사 요약입니다. GitHub가 자동 제공하는 Source code ZIP/TAR는 개발용 소스이며 설치 프로그램이 아닙니다.

설치 파일은 코드 서명되지 않았습니다. 지원 대상은 Windows x64이며 모든 PC 구성에서의 호환성을 보장하지 않습니다. 설치 실패 시 설치 폴더의 `install.log`에서 실패 단계를 확인하세요.

HWP는 읽기 전용이고 HWP/HWPX는 원래 쪽 배치 대신 추출 내용을 표시합니다. PDF·이미지는 영역 가림을 지원하며 새 문구 교체는 지원하지 않습니다. 검출 0건도 개인정보가 없다는 보장은 아니므로 공유 전 원문과 수정 사본을 직접 검토하세요.

## 확인 순서

1. 프로그램의 **파일 검사 → 파일 추가**에서 `formats/files/`의 문서만 선택하거나 해당 파일을 파일 검사 화면에 **드래그 앤 드롭**합니다. 폴더 전체는 지원하지 않습니다. 한 번에 최대 8개이므로 나눠 검사하세요.
2. 위험도별 후보를 누르고 실제 위치와 원문을 비교합니다.
3. 형식에 따라 지원하는 부분 가림·전체 가림·직접 수정을 지정하고 **원본 / 적용 미리보기**로 비교합니다. HWP는 확인만 가능합니다. 처리 방법을 지정하지 않은 항목은 원문 그대로 남습니다.
4. **사본 생성·재검사 → 실제 사본 확인** 후 남은 후보와 가림 범위를 검토합니다. **남은 후보, 이미지 가림 범위, 지원 제한을 확인했습니다.**를 체크한 뒤 새 파일로 저장합니다.

## 이미지 수정 확인하기

1. 10번 PNG, 11번 JPG, 12번 JPEG 중 하나를 열고 검출된 이름이나 연락처를 선택합니다.
2. **직접 수정**을 누르고 **바꿀 내용** 입력란에 `담당자` 등 짧은 문구를 입력합니다. 한 줄 80자 이하이며, 빈 문구는 해당 원문을 지웁니다.
3. **적용 미리보기**에서 변경 모습을 확인합니다. 부분 가림은 `박**`, `010-****-2103` 같은 문구를, 전체 가림에 해당하는 **비공개 표시**는 `비공개`를 새로 씁니다. **직접 영역 가리기**는 검은 가림입니다.
4. 필요하면 일반 특수문자나 `✓`를 입력해 표시를 확인합니다. 로컬 글꼴이 지원하지 않는 문자·공간 부족·수정 영역 겹침은 경고가 나오며, 문제가 해결되기 전에는 사본을 생성할 수 없습니다. 오류 영역은 원문으로 남거나 오류 안내와 함께 원본이 표시될 수 있습니다.
5. 사본 생성·재검사 후 실제 사본을 확인하고 저장합니다. 세 이미지 형식 모두 **PNG 사본**으로 저장하며 원본에 덮어쓰지 않습니다.

사진·복잡한 배경·원본 글꼴은 다르게 보일 수 있습니다. 미리보기만 보고 완료로 판단하지 말고 저장한 이미지에서도 문구와 주변 글자·표 선을 확인하세요.

## 다른 형식의 확인 범위

DOCX의 메모·작성자·속성, PPTX의 발표자 노트, XLSX의 숨김 시트에도 정보가 있습니다. **텍스트 · 위치**에서 본문 화면 밖의 위치도 확인하세요. HWP는 읽기 전용이고 HWP/HWPX 내용 화면은 원래 쪽 배치를 재현하지 않습니다. PDF 페이지와 DOCX·PPTX·HWPX에서 읽어낸 지원 내장 이미지는 검은 영역 가림을 사용하며 문구 직접 수정은 비활성화됩니다.

XLSX는 지원 수식 재계산 후 값 전용 사본을 만들며, 수식을 유지한 편집은 지원하지 않습니다. 그림·차트·필터·외부 연결 등이 있는 다른 XLSX는 검사가 제한될 수 있습니다. PDF는 주석·링크·서명 등 구조에 따라 사본 생성을 제한하며, 저장 가능한 경우에도 목차·문서 속성 등은 보존하지 않습니다. 자세한 범위는 [지원 파일과 제한](../README.md#지원-파일과-제한)을 확인하세요.

일정·작성일과 생년월일을 구분하고 `1세트` 같은 수량이 나이로 잡히는지, 수정한 뒤 이름·전화·주소가 의도대로 바뀌고 공개 일정·표가 유지되는지도 살펴보세요. 이미지는 선명한 기본 예시이며 저화질·필기·기울기 성능을 대표하지 않습니다. 검출 후보 수만으로 전체 정확도를 판단하지 마세요.

## 확인 순서

1. 프로그램의 **파일 검사 → 파일 추가**에서 `formats/files/`의 문서만 선택합니다. 한 번에 최대 8개이므로 나눠 검사하세요.
2. 위험도별 후보를 누르고 실제 위치와 원문을 비교합니다.
3. 부분 가림·전체 가림·직접 수정을 지정하고 **원본 / 적용 미리보기**로 비교합니다.
4. **사본 생성·재검사** 후 실제 사본과 남은 후보를 확인하고 새 파일로 저장합니다.

DOCX의 메모·작성자·속성, PPTX의 발표자 노트, XLSX의 숨김 시트에도 정보가 있습니다. 본문 화면 외의 위치도 확인하세요. HWP는 읽기 전용이고 HWP/HWPX 내용 화면은 원래 쪽 배치를 재현하지 않습니다. PDF와 문서 내장 이미지는 문구 교체를 지원하지 않습니다.

일정·작성일과 생년월일을 구분하고 `1세트` 같은 수량이 나이로 잡히는지, 수정한 뒤 이름·전화·주소가 의도대로 바뀌고 공개 일정·표가 유지되는지도 살펴보세요. 이미지는 선명한 기본 예시이며 저화질·필기·기울기 성능을 대표하지 않습니다. 검출 후보 수만으로 전체 정확도를 판단하지 마세요.
